# NetWatch - Network Traffic Analyzer

## Overview
A Python-based network traffic analysis tool
using Scapy.

## Features
- PCAP file analysis
- IPv4 packet inspection
- TCP, UDP and ICMP identification
- Source IP statistics
- Destination port analysis
- Possible port scanning detection
- Automated report generation

## Technologies
- Python
- Scapy
- Wireshark
- Git

## How to Run

Install dependencies:

pip install scapy

Generate sample traffic:

python netwatch/generate_sample.py

Analyze traffic:

python netwatch/network_analyzer.py

## Disclaimer
This project uses synthetic network traffic
for educational purposes.
